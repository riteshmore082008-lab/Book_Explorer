# 📚 Book Explorer

## About

Book Explorer is an Android application developed using Java and Android Studio.
It allows users to search and explore books using the Open Library API.

## Features

- 🔍 Search books
- 📚 Browse books
- 🖼️ Display book covers
- 📖 View book details
- 🌐 Fetch data from API

## Technologies Used

- Java
- Android Studio
- Retrofit
- REST API
- Gson
- RecyclerView
- Glide
- SearchView
- Intent
- Material Design

## API Used

Open Library API
